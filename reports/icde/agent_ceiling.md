# Agent ceiling exploration (C-max): what a less constrained single-controller agent reaches

Generated by `scripts/agent_ceiling_report.py` (do not edit). **Exploratory, not part of the frozen protocol**: the configuration was
specified after the frozen study (`reports/icde/agent_protocol_v1.md`, results in `agent_results.md`) from validation data, then run once on the
same 659-window cohort. Every variant is reported; failures stay in the denominator (ADE +inf, route 0); rates pool the nominal seeds and are
bootstrapped by driver (1,000 resamples, 95 % percentile intervals); the frozen study's files were not touched.

## 1. Configuration

- Model `Qwen/Qwen3-14B` revision `40c069824f4251a91eefaf281ebe4c544efd3e18`, bf16, vLLM, thinking mode with the model card's sampling values; served context 16,384 tokens (the run manifests record the config hashes: budget `5353ae9527f0`, sampling `c4d0cff64a25`, prompt `dd9f841ee2ac`, schema `a1dd6e785ca5`, selector `08fd6a91cc59`; tool-cache code sha `0e223df90051`, cache version 2).
- Reconstructor presets (10): beam, beam_loose, beam_wide, ep, ep_hm, pf, pf_s1, pf_s2, pf_s3, pf_s4; each may be run once per window; candidates come from the cache that replays `run_baseline.py` exactly (identity check in `agent_max_results.md`).
- Concurrency 24; selector tool on; cohort sha `d026d236e21a`.
- Controller budget: 12 turns, 40 tool calls plus 1 reserved submit, 24,576 generated tokens (reserve 512, per turn 6,144), virtual clock 1800 s; forced final submit with thinking off.
- Critic budget: 4 turns, 8 tool calls plus 1 reserved submit, 8,192 generated tokens (reserve 512, per turn 4,096), virtual clock 600 s; forced final submit with thinking off.
- B-max selector: logistic model over 19 observable features (`configs/agent_max/selector_max.json`; fitted on the cached validation windows, validation cross-fit in `reports/icde/tables/agent_selector_max_val.csv`).
- Tools (6): `run_reconstructor`, `inspect_candidate`, `compare_candidates`, `score_candidates`, `query_local_graph`, `submit_choice`; the controller sees only candidates of reconstructors it has run and may submit only those.
- Prompt: `configs/agent_max/system_prompt.txt` with calibration hints computed on validation candidates only (`reports/icde/tables/agent_max_val_hints.csv`); critic prompt `configs/agent_max/critic_prompt.txt`.

## 8. Pre-specified rule for the paper

Stated before the three seeds, the critic and the vote had finished: the candidate for the main text is the single controller with three seeds
(row `agent`); critic and vote stay in the supplement as variants. It replaces the frozen configuration in Section VI-F only if its seed-pooled
route recovery is at least the frozen configuration's on both folds; if it is higher on one fold and lower on the other, the main text keeps the
frozen study and gains one sentence pointing to this exploration in the supplement. Interpretation follows the stats wording rules (a CI that
includes 0 is 'no clear evidence').
